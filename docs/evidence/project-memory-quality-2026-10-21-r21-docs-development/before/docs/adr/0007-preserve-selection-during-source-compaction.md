# Preserve selection during source compaction

Repeated quotation metadata consumes the fixed context budget. Repricing every candidate after compaction can admit an earlier group that displaces previously visible evidence. We retain the primary selection, compact its XML, then append only complete complementary source groups that fit the saved space.

Quotation references share original provenance only. The root declares `quote_refs="provenance_only"` when references appear. Each association keeps its own scope, history, custody, uncertainty and field purpose. Unknown pointer qualifiers remain explicit. A source reference cannot transfer these qualifiers from another container. Different source fields, roles, tool calls and events remain distinct.

An independently qualified whole original in source custody remains eligible when a historical `prior_*` field cites it. Its disposition and unresolved applicability remain explicit. Showing the original does not reactivate a historical requirement. This refines the transport policy in [ADR 0006](0006-expanded-neutral-original-context.md).

## Consequences

Compaction retains the actual command, exit code and complete output together. Only a strictly checked native pair can share its repeated completeness metadata. Unknown or conflicting metadata remains. Source selection, model profiles, storage and neutral pool limits stay unchanged. The [transport helper](../../codex_mem/project_memory_source_transport.py) performs no I/O.

The mandatory reference declaration has a real size. If the selected compacted XML cannot fund it, primary packing retries once with that size reserved. Refill preserves the resulting selection. Both brief construction and the public renderer use the [same final rendering step](../../codex_mem/project_memory_retrieval.py).

Primary admission keeps conservative canonical prices. A compact group can therefore fit in isolation but still miss primary admission at that budget. We accept this capacity tradeoff to preserve selected evidence during compaction. The renderer does not promise maximal packing. Added original quotations do not restore omitted canonical field associations or clear their omission counters.

The [disclosed replay](../evidence/project-memory-quality-2026-10-21-r17/development-v7/central-render-assessment/result.json) checks source visibility. It does not establish answer quality or production behavior. A fresh independent comparison must still satisfy the existing quality gates. Earlier failures and scores remain unchanged.
