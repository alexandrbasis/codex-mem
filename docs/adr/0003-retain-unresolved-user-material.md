# Retain unresolved user material after processing

Completing background processing can hide a user requirement that extraction omitted. Keep neutral source custody separately from episodes and claims. A processing cursor records consumed observations. It does not establish complete representation of their meaning.

Custody covers newly consumed user material without classifying it as an active requirement. Its uncertainty concerns the extracted representation. It does not cancel an explicit request in the source. Only an exact claim covering the whole source establishes its stored representation. A valid scoped closing relation can establish completion. Partial clauses, paraphrases, replacement and uncertain cancellation retain an unresolved remainder. Historical quotations cannot activate a requirement.

This conservative choice retains ordinary user material and increases context and storage pressure. Bounded retrieval reports omissions. Ordinary age pruning protects unresolved sources, while explicit deletion still revokes them. There is no automatic history backfill. A later semantic association method must measure both false acceptance and useful material lost before replacing this fallback.
